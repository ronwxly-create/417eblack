# 417 E Black St listing site

Pages
- /           all three offices
- /office-1   /office-2   /office-6   (one link per Facebook post; each has its own preview image)

Tip: add ?src= to links so the lead log shows where people came from, e.g.
  https://417eblack.com/office-2?src=fb-rockhill-biz-group

Tour requests are emailed to info@nexthomepm.com (via FormSubmit, free, no account).
The VERY FIRST request sends an "Activate" email to info@nexthomepm.com. Someone must click it once,
or later requests won't arrive. Send a test request right after launch and activate it.

Phone and email live in config.js.

Deploy: push this folder to a GitHub repo, import it in Vercel, add 417eblack.com in Vercel > Domains,
then set the DNS records Vercel shows in GoDaddy.
